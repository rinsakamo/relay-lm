# Actual-model production Continuity retained-formation overlay diagnostic

This reference owns the evaluation-only #2593 discriminator used after #2529 established epistemic formation and #2583 established isolated projection into the canonical Continuity wire.

It does not change production cognition or Continuity semantics. Its question is narrower:

> Does the formed T2 meaning survive the complete ordinary production extraction task when that meaning is made explicit without supplying a Continuity answer?

## Scientific split

```text
P2a — formation-to-extraction access/coupling failure
  explicit retained meaning + full production extraction -> correct unresolved set

P2b — post-formation production multiplexing/interference
  explicit retained meaning + full production extraction -> still absent/materially wrong
```

A transport, provenance, T1-parity, or protocol failure supports neither outcome.

## Production path

The physical producer runs only the first two turns of the current authoritative `continuity-lifecycle-v1` scenario through ordinary `run_user_turn_two_pass`:

```text
T1 production Pass 1
  -> T1 production Pass 2
  -> accepted T1 State/Continuity through existing deterministic authority
  -> T2 production Pass 1
  -> T2 production Pass 2 built by the canonical production builder
     + one evaluation-only retained-formation overlay
```

Maximum semantic generation count is four. Formation is never regenerated and T3 is never executed. T1 Pass 2 must commit before T2 is attempted; otherwise the producer stops without P2a/P2b inference rather than synthesizing accepted Continuity.

## Retained evidence contract

The input artifact is retained #2529 formation evidence. Its one semantic item must contain exactly `subject_span`, `unknown_evidence_span`, and `source_event_id`. It must not contain a Continuity kind, key, operation, value, evaluator/scorer label, expected answer, or repair instruction.

Before semantic execution the producer verifies the retained diagnostic identity and mechanical validation, exactly one retained item, the stable Stage-R turn-2 source identity, and exact substring grounding against current authoritative T2.

## Run-local provenance rebind

Ordinary production creates a fresh user Event ID for every turn. #2529 instead retained a stable diagnostic Stage-R source ID. Literal equality would require changing production Event identity and would add a second intervention.

At T2 Pass 2 the diagnostic therefore requires the fresh production current-input content to equal authoritative T2 byte-for-byte and revalidates both spans. Only then it normalizes the overlay `source_event_id` to the run-local current T2 Event ID required by canonical production source validation.

A non-model-facing binding artifact records `retained_source_event_id`, `run_local_source_event_id`, and `provenance_rebound=true`. The text spans are unchanged. This is provenance transport normalization, not semantic transformation.

## Request parity

The diagnostic first calls canonical production `_extraction_request_body` with the same CognitiveInput, fresh Pass 1 response, production system instruction, State task, Continuity task/rules/examples, native production schema, decoding, and explicit reasoning-OFF realization. It then deep-copies that exact request and appends one tagged `RETAINED_FORMED_OBSERVATIONS` block to the user message.

The generic notice says only that the source-grounded semantic observations are empirical and non-authoritative and may be considered during the unchanged ordinary extraction task. It prescribes no output.

Both the pre-overlay production request body and final overlay request body are retained so structural parity can be audited directly.

## Output and review boundary

T2 output uses the unchanged production native schema, canonical extraction parser, and canonical source checks. There is no parser, Validator, materializer, lifecycle, oracle, or scorer relaxation.

A mechanically valid four-generation transaction stops as `PROTOCOL_VALID_SEMANTIC_REVIEW_REQUIRED`. The physical producer does not classify P2a/P2b; later zero-generation review reads retained T1/T2 evidence.
