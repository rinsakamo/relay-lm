# Character realization review checklist

This checklist is a reviewer aid for #1823 and does not create a weighted score.

For each reviewed turn or bounded scenario, ask:

- Is the response/interpretation plausible for the frozen Character?
- Is any surprising behavior still explainable by SOUL, governed experience,
  and accepted current understanding?
- Did RelayLM preserve real actor/source/subject provenance?
- Did the Character fabricate a remembered occurrence or unsupported history?
- Is clarification calibrated to context, interruption, restart, or elapsed time?
- Did distinct Characters collapse into the same generic assistant pattern?
- Is any observed failure better attributed to runtime authority than to
  Character interpretation?

Record Character-plausible oddity without automatically promoting it to a
failure. Escalate `out_of_character` and `system_defect` separately.
